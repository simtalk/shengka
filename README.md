- 📊 **详细信息** - 显示声卡名称、驱动、状态等信息

## 🚀 快速开始

### 本地运行

```bash
# 克隆项目
git clone https://github.com/你的用户名/sound-card-checker.git
cd sound-card-checker

# 直接运行（需要Python 3.8+）
python sound_card_checker.py
```

### 下载已编译版本

前往 [Releases](https://github.com/你的用户名/sound-card-checker/releases) 页面下载最新的 `声卡检测V1.0_知一科技.exe` 文件。

## 🔧 自动构建

本项目配置了 GitHub Actions，每次推送到 `main` 分支或创建 Release 时，会自动构建 Windows 可执行文件（.exe）。

### 手动触发构建

1. 进入项目的 **Actions** 页面
2. 选择 **Build EXE** 工作流
3. 点击 **Run workflow**
4. 等待构建完成后，在 **Artifacts** 中下载生成的 .exe 文件

### 构建产物

构建成功后，你可以获得：
- `声卡检测V1.0_知一科技.exe` - Windows 可执行文件
